# PadelSpot – Padel Court Rental Information System

## 1. Project Overview

PadelSpot is an individual academic project focused on the analysis and design of a web-based information system for padel court rental management.

The proposed system aims to streamline the court rental process by enabling customers to register, log in, view available courts, check schedules, make reservations, complete payments, and receive digital booking confirmations.

The system also provides administrative capabilities for managing court information, rental schedules, pricing, booking transactions, payment verification, and rental reports.

This project was developed as part of an academic assignment in Information Systems Analysis and Design (APSI).

## 2. Project Objectives

The main objectives of this project are:

- Analyze the existing padel court rental business process.
- Identify business and system requirements.
- Design an improved online court reservation process.
- Define system actors and their interactions.
- Model business processes, system workflows, and data structures.
- Develop a UI/UX prototype based on the proposed system requirements.

## 3. Proposed System Scope

The proposed system involves three main actors:

### Customer

- Register and log in to the system.
- View available padel courts.
- Check court schedules and availability.
- Make court reservations.
- Complete payment transactions.
- Receive digital booking confirmations.

### Administrator

- Manage court information.
- Manage rental schedules and pricing.
- Manage booking transactions.
- Verify payment status.
- Generate rental and transaction reports.

### Payment Gateway

- Process payment transactions.
- Provide payment status information.
- Support transaction verification.

## 4. Business Process Analysis

The project includes an analysis of the existing (As-Is) and proposed (To-Be) business processes.

The analysis focuses on improving the court reservation workflow, organizing booking administration, minimizing scheduling conflicts, and supporting more structured payment management.

Business process modeling is used to illustrate the proposed operational flow and interactions between system actors.
